# Rangpur Learning Grounds MVP

This is a separate static website project for an experiential learning venue concept in Rangpur.

## Current scope

- Landing page for the experiential learning concept
- Audience-specific sections for schools, colleges, and corporates
- Planning sections for land structures, operations, and future backend needs
- Interactive program tabs and an MVP inquiry form

## Tech stack for this version

- `HTML`
- `CSS`
- `JavaScript`

## Suggested next stack

When you want real data and admin workflows, move this into a Python backend:

1. Use `Django` for forms, admin panel, and content management.
2. Use `PostgreSQL` for leads, bookings, facilitators, programs, and follow-ups.
3. Add image galleries, testimonials, downloadable brochures, and real inquiry storage.
4. Later add bookings, waivers, pricing workflows, invoices, and reporting.

## Files

- `index.html` - website structure and content
- `styles.css` - styling, layout, and responsive behavior
- `script.js` - navigation, tabs, dashboard shuffle, and form interaction
