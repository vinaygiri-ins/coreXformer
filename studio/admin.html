What should happen after a review decision

How to use it

The simplest working flow for outreach discovery

  • Start with geography Move the map to the city, district, or neighborhood you want to cover and use the current view as the scan area.
  • Pick the institution types Choose whether you want only schools, only colleges, or a broader mix that includes offices, communities, and government anchors.
  • Save only the useful leads Do not keep everything. Save the organizations that seem relevant for meaningful experiential learning outreach.
  • Use the saved board as your private pipeline Capture status, priority, notes, next follow-up, and the best person to approach so the research becomes actionable.

Current storage

For this first version, saved leads and notes stay private in this browser on this device. That keeps the module lightweight while we refine the real workflow before moving it into shared backend records.
