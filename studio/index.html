Operational view

What this studio will control

  • Public content Hero copy, deep-dive articles, audience cards, founder details, contact content.
  • Inquiry flow New, contacted, scheduled, and closed inquiry states from the website form.
  • Publishing Draft and published states so the live site only shows approved content.
  • Future media Founder image, session photos, gallery assets, and testimonial visuals.

Important boundary

Admin editing should update content records in the backend. It should not directly rewrite layout code. That keeps the design stable while letting you update words and sections freely.
